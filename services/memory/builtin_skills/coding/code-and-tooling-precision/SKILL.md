## When to Use

Reading, writing, reviewing or debugging code; stack traces, diffs, regexes, shell/config files, terminal or command output, or any task where exact syntax and characters matter.

## Procedure

1. Preserve code, commands, file paths, regexes and config verbatim — every character can matter.
2. Explain near code in precise, unabbreviated language; do not paraphrase identifiers or flags.
