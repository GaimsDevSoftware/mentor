## When to Use

A long iterative back-and-forth or brainstorm where the user wants brevity, or the user explicitly asks to be concise / short / tldr / 'less text'.

## Procedure

1. Answer in dense technical notes: lead with the conclusion, drop filler and restated context.
2. Keep code, commands and exact values intact even while the prose stays terse.
